# 行伴 · 户外安全同行

面向户外出行的交互原型，覆盖海岸、山地、森林、戈壁等示例场景。

## 本地运行

直接用浏览器打开 `index.html`，或在项目目录运行：

```sh
python -m http.server 8766
```

访问 http://localhost:8766 。无需安装前端依赖。

## 功能

- 行程登记、报平安、求助及行程结束
- 附近队伍、人员状态与通知
- 模拟断网记录、联网同步与记录导出
- 示意地形、路线、现场标记

详细操作见 [使用说明](使用说明.md)。

## 原型边界

地图、定位、人员和救援信息均为模拟数据。未连接真实定位、通信、通知或救援服务，请勿用于实际导航或应急救援。用户输入保存在各自浏览器的 localStorage，不随源代码上传。
